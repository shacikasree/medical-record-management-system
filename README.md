Medical Record Management System

About

A web-based healthcare application for managing patients, doctors, appointments, prescriptions and medical records digitally.

Modules
1. Administrator
2. Doctor
3. Patient
4. Laboratory Management
5. Electronic Medical Records
6. Reports & Analytics

Technologies

Frontend  : JSP, HTML, CSS, JavaScript
Backend   : Java Servlets
Database  : MySQL
Server    : Apache Tomcat
IDE       : NetBeans
Build     : Maven

Main Features

1. Patient registration and login

2. Doctor management

3. Appointment booking

4. Prescription management

5. Patient medical history

6. Laboratory report management

7. Medical document management

8. Reports and analytics
